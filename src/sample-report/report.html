9. Method and limits

  • Model as returned: gpt-5.6-luna. Requested: gpt-5.6-luna.
  • Search tool: web_search. Location: US. Language: en.
  • Answers collected 2026-10-30 to 2026-10-30: 24 prompts, 6 intents, 280 usable answers (0 failed, 0 excluded).
  • Stopping rule: at least 10 runs per prompt, then 10 more at a time while an intent's 95% interval is wider than ±10 points, up to 100 runs per prompt. A round stops early if more than 10% of its calls fail.
  • Prices used: $0.20 per million input tokens, $1.20 per million output tokens, $0.01 per search. Total cost, failed and excluded calls included: $4.19.
  • Of 280 usable answers, 280 used the web search tool at least once (100% (n=280, 99%–100%)); the others were answered without searching.

Limits

  • The API is not the app. People using the ChatGPT app may see different answers.
  • Intervals are approximate. Runs were added until the target was met, which makes the stated 95% intervals approximate.
  • Only whether a brand is mentioned is measured. Where in an answer a brand appears is not, and a brand named first counts the same as one named last.
  • Matching is deterministic text matching. It misses misspelt brand names and any name that is not among the configured names and aliases.
  • First-party data shows visits, not visibility.

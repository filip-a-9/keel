How ordering works

  1. Choose a tier and email the 8-question intake: brand, aliases, domains, competitors, country, buyer questions, pages to be cited and tier.
  2. Keel confirms the scope, and the question themes if you asked for suggestions.
  3. After the order is confirmed, Keel emails a Payoneer payment request in GBP. The full amount is paid up front.
  4. Work starts when payment arrives. The report is emailed within the stated working days.

Revisions and refunds

  • One round of revisions to the report text and to the question themes is included.
  • Full refund if you cancel before answer collection starts.
  • No refund once answers have been collected.

Which one should you pick?

Choose Snapshot if you want to know where you stand in ChatGPT and decide afterwards whether more is needed. Choose Full if you want Claude covered as well, a wider set of themes, and a written list of actions. Agencies buying for a client usually want Full, because the findings and actions are what a client acts on, and both tiers are white label. See white-label audits for agencies.

What is not included

  • No guaranteed rankings, mentions or traffic. The audit measures; it does not change what AI assistants say.
  • No coverage of the consumer ChatGPT or claude.ai apps. Answers come from the API and Claude Code and may differ from what an individual user sees.
  • No monthly monitoring. Each audit is a one-off snapshot in time. Mention rates drift as models and the web change.
  • Only whether a brand is mentioned is measured, not where in the answer it appears.
